### 개발 문서 색인

Claude (AI 작업자)가 코드를 고치기 전에 읽는 개발 문서다. 사용자용 설명은 `docs/GUIDE.md`, 기능별 변경 이력은 `docs/CHANGES.md`에 있다.

기준 시점: 2026-10-05 (버전 `2.8.0-swh.17`, upstream `v2.8.0-beta` 기반).

#### 출처 표시

| 표시                       | 뜻                                                                  |
|----------------------------|---------------------------------------------------------------------|
| `[upstream]`               | upstream `v2.8.0-beta`에 이미 있던 것                               |
| `[fork #N]`                | 포크가 추가한 것. N은 `docs/CHANGES.md` 섹션 번호                   |
| `[upstream, fork #N 변경]` | upstream 것을 포크가 바꾼 것                                        |
| `[fork]`                   | 대응하는 CHANGES 섹션이 없는 포크 변경                              |
| (추정)                     | 코드나 기록에서 도출한 추론. 실행으로 확인하지 않음                 |
| (기록 없음)                | 이유가 코드, 주석, 커밋, CHANGES 어디에도 기록되지 않음             |
| (로컬 기록)                | 저장소 밖의 작업 기록에만 있는 사실. 저장소 안에서는 확인할 수 없음 |

판정 기준은 `git diff --name-status v2.8.0-beta`다. 이 목록에 없는 파일은 upstream 그대로다.

#### 갱신 규칙

- 코드를 바꾸는 작업을 마칠 때, 아래 표에 해당하는 문서를 같은 작업 안에서 고친다.
- 문서와 코드가 다르면 코드가 기준이다. 불일치를 발견하면 문서를 고친다.
- 근거는 경로와 심볼 이름으로 단다. 줄 번호는 쓰지 않는다.
