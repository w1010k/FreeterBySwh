## 1. 마인드맵 위젯 *(조사: 2026-04-23)*

**목표 수준**: FreeMind 급 (탭=자식 추가, 엔터=형제 추가, 접기/펼치기, 인라인 편집, 드래그로 재부모화, 노드 스타일링).

### 접근 방향

직접 구현(d3-hierarchy + SVG + 키바인딩 + DnD)하면 공수가 너무 크다. FreeMind 스타일 인터랙션을 이미 제공하는 OSS 라이브러리를 **한 겹 감싸는** 방향이 현실적.

### 후보 라이브러리

| 이름 | 특징 | 비고 |
|---|---|---|
| [mind-elixir](https://github.com/ssshooter/mind-elixir-core) | FreeMind 스타일 인터랙션, 키보드 단축키, 드래그 재배치, 노드 스타일링 내장. 현대적 외관. | 유력 후보 |
| [jsMind](https://github.com/hizzgdev/jsmind) | MIT, `.mm` (FreeMind 원본 파일) import 지원. 스타일은 다소 올드. | 호환성 우선 시 |

**착수 전 확인할 것**:
- 라이선스 (상용 배포 호환 여부)
- 번들 크기 (Electron 앱이라 관대하긴 하나 체크)
- Electron + React 19 환경에서 마운트/언마운트 안정성
- **한글 IME 입력** 정상 동작 여부 (인라인 편집에서 조합 중 이벤트 충돌 이슈가 종종 있음)
- 터치/휠 줌 동작

### 위젯 관점에서 할 일

1. `src/renderer/widgets/_template/` 복사해서 스켈레톤 구성
2. 라이브러리 마운트 + `onChange` 이벤트로 JSON 받아 settings state에 저장
3. 설정 에디터에서 초기 데이터(루트 노드 이름 등) 편집
4. (선택) FreeMind `.mm` import/export 버튼 — jsMind 선택 시 거의 공짜

### 공수 예상

- MVP (뷰/편집/저장): **3~5일**
- FreeMind `.mm` 호환까지: **1~1.5주**

직접 구현 대비 70~80% 절약되는 그림.

### 까다로울 것으로 예상되는 포인트

- **상태 저장 경로**: 마인드맵 데이터가 커질 수 있음 → 위젯 settings에 인라인으로 둘지, 위젯별 데이터 폴더(`<appData>/freeter2/freeter-data/widgets/<widgetId>`)에 별도 파일로 둘지 결정 필요.
- **undo/redo**: 라이브러리 기본 제공이면 그대로 쓰고, 없으면 포기하거나 Zustand 상태 스냅샷 기반으로 직접 구현.
- **다크/라이트 테마**: 라이브러리 테마 연동 또는 CSS 오버라이드.
- **한글 IME**: 위 "확인할 것"과 동일 — 사전 스파이크 필수.
