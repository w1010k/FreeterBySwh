## 0. 프리터가 뭔가요?

**프리터(Freeter)는 컴퓨터로 일하는 사람을 위한 무료·오픈소스 정리 도구입니다.**

업무에 필요한 모든 것 — 자주 쓰는 웹앱·웹페이지, 메모, 할 일, 파일·폴더, 타이머, 계산기까지 — 을 **위젯**으로 만들어 **프로젝트별 작업판**에 한곳에 모아둡니다. 그리고 단축키(`Ctrl`/`Cmd`+`Shift`+`Space`) 한 번이나 시스템 트레이 아이콘으로 언제든 불러내고, 워크플로우(작업판 탭) 사이를 매끄럽게 전환합니다.

핵심 가치는 단 하나 — **컨텍스트 스위칭 비용을 줄이는 것**입니다. 일을 바꿀 때마다 창을 찾아 헤매고, 북마크를 뒤지고, 탭을 다시 여는 그 시간을 없애줍니다.

### 이런 분에게 좋아요

- 여러 프로젝트·고객사·사이드 작업을 **동시에** 오가는 사람
- 브라우저 탭이 수십 개로 폭발해서 정작 필요한 걸 못 찾는 사람
- 매일·매주 **반복되는 리서치나 루틴**이 있는 사람
- 작업마다 "필요한 도구 세트"가 정해져 있어서 그걸 한 화면에 띄워두고 싶은 사람

## 1. 왜 쓰면 좋을까

기능 나열보다, 실제 쓰는 모습으로 보는 게 빠릅니다. 아래 네 가지 흐름이 프리터의 이점을 가장 잘 보여줍니다.

### 시나리오 ① — 프로젝트를 갈아끼우듯 전환

고객사 A와 B를 각각 **프로젝트**로 분리해 둡니다. A 프로젝트엔 A의 웹 콘솔·문서·할 일이, B 프로젝트엔 B의 것이 들어 있죠. 트레이 아이콘이나 단축키로 프로젝트를 바꾸면 **화면 전체가 그 프로젝트 세트로 통째로 갈아끼워집니다.** 머릿속으로 "지금 뭐 하던 중이었지"를 다시 떠올릴 필요가 없습니다.

### 시나리오 ② — 리서치 작업판

화면 하나에 **Webpage** 위젯으로 자주 보는 레퍼런스 사이트를 임베드하고, 옆에 **Web Query** 위젯으로 검색창(구글·네이버·나무위키·ChatGPT 등)을 띄우고, 아래엔 **Note** 위젯으로 메모를 적습니다. 탭을 새로 열고 닫을 일 없이, "조사하는 화면"이 항상 그 모양 그대로 준비돼 있습니다.

### 시나리오 ③ — 데일리 루틴

**To-Do List**(같은 프로젝트 안에서 자동으로 동기화됨) + **Pomodoro**(집중/휴식 반복 타이머) + **D-Day**(마감 카운트다운) + **Clock**(세계시계)를 한 워크플로우에 모아두면, 하루를 여는 대시보드가 됩니다.

### 시나리오 ④ — 개발/운영 대시보드

**File Explorer**(즐겨찾기 폴더 트리) + **Commander**(자주 쓰는 명령을 클릭 한 번에 터미널 실행) + **Link/File Opener**(링크·파일을 버튼 하나로 열기) + **System Monitor**(CPU·RAM 실시간)를 묶으면, 손이 자주 가는 운영 도구들이 한 판에 모입니다.

## 2. 5분 빠른 시작

### 1) 설치·실행

이 포크 버전은 소스에서 직접 빌드합니다(원본 설치 파일을 바로 쓰고 싶다면 [원본 다운로드 페이지](https://freeter.io/download) 참고). 빌드 순서는 [README의 "소스에서 직접 빌드하기"](../README.md#소스에서-직접-빌드하기)에 있습니다 — 요약하면 `yarn` → `yarn run prod` → `yarn run package`.

처음 실행하면 비어 있는 작업판이 나타납니다. 여기서부터 시작합니다.

### 2) 편집 모드 켜기 — 모든 편집의 스위치

프리터는 평소엔 **보기 모드**(깔끔하게 사용만), 무언가를 추가·이동·삭제할 땐 **편집 모드**로 전환해서 씁니다.

- 좌측 상단의 **연필 아이콘**을 클릭하거나, 메뉴 **Edit → Enable Edit Mode** (`Ctrl`/`Cmd`+`E`).
- 편집 모드에서만 위젯을 추가·이동·리사이즈할 수 있고, 각 위젯에 액션바(설정·삭제 아이콘)가 나타납니다.

### 3) 프로젝트 만들기

- 프로젝트 스위처(드롭다운) 옆 **Manage Projects**(기어 아이콘) 또는 메뉴 **View → Manage Projects**.
- 대화상자에서 **Add Project** → 오른쪽 패널에서 이름을 입력합니다.
- 프로젝트 전환은 상단의 **프로젝트 드롭다운**에서 선택하면 즉시 바뀝니다.

### 4) 워크플로우(탭) 추가

- 워크플로우는 한 프로젝트 안의 **작업판 탭**입니다.
- 편집 모드에서 탭 바의 **`+`** 로 새 탭을 추가하고, 탭을 **우클릭 → Rename**으로 이름을 바꿉니다.

### 5) 위젯 올리기

- 편집 모드에서 **팔레트의 "Add Widget"** 목록에서 원하는 위젯 타입을 **작업판 격자로 드래그**(또는 클릭)합니다.
- **이동**: 위젯을 잡고 드래그. **리사이즈**: 모서리·가장자리의 핸들을 드래그.
- 격자는 반칸 단위로 촘촘하게 배치할 수 있습니다.

### 6) 위젯 설정 열기

- 편집 모드에서 위젯 헤더의 **기어(설정) 아이콘**을 클릭합니다.
- 위젯이 너무 작아 아이콘이 잘리면 **`...`(더보기) 메뉴**에서 설정·삭제에 접근할 수 있습니다.
- 위젯 **우클릭**으로도 설정·복사·삭제 메뉴가 나옵니다.

### 7) 언제든 불러내기

- 글로벌 단축키 **`Ctrl`/`Cmd`+`Shift`+`Space`**(이 포크 기본값)로 어디서든 프리터를 앞으로 불러내고, 다시 누르면 숨깁니다.
- 또는 **시스템 트레이 아이콘** 클릭(우클릭하면 프로젝트 목록에서 바로 전환).

### 8) 편집 모드 끄고 사용 시작

다 배치했으면 연필 아이콘으로 편집 모드를 끄고(`Ctrl`/`Cmd`+`E`) 쓰면 됩니다. 끝!

## 3. 핵심 개념 정리

```
프로젝트 (Project)            ← 고객사·업무 단위. 트레이/드롭다운으로 전환
  └─ 워크플로우 (Workflow)     ← 프로젝트 안의 작업판 "탭". Ctrl/Cmd+Tab으로 순환
       └─ 위젯 (Widget)        ← 격자 위에 올리는 도구 (Note, Webpage, Timer ...)

탑 바 (Top Bar) / 셸프 (Shelf) ← 프로젝트·워크플로우와 무관하게 "항상 보이는" 빠른 접근 영역
```

| 용어 | 뜻 |
|---|---|
| **프로젝트** | 가장 큰 단위. 보통 고객사·제품·역할별로 나눕니다. 전환하면 작업판 전체가 바뀝니다. |
| **워크플로우** | 한 프로젝트 안의 작업판 탭. "리서치", "운영", "회의" 식으로 나눕니다. |
| **위젯** | 작업판 격자에 올리는 개별 도구. 16종 제공(4장 참고). |
| **탑 바 / 셸프** | 화면 상단(또는 측면)의 항상 보이는 영역. 프로젝트와 상관없이 늘 곁에 둘 위젯을 올립니다. 워크플로우 전환·프로젝트 관리 버튼도 여기 있습니다. |
| **편집 모드** | 위젯·탭을 추가/이동/삭제할 수 있는 상태. 평소엔 보기 모드로 두고 씁니다. |
| **메모리 세이버** | 한동안 안 본 워크플로우를 메모리에서 자동으로 내려 자원을 아끼는 기능. 다시 열면 복구됩니다(앱 설정에서 임계값 조정). |

> 워크플로우 바(탭이 있는 줄)와 편집 모드 토글·프로젝트 스위처의 **위치**는 메뉴 **View → Appearance**에서 위/아래/좌/우로 바꿀 수 있습니다.

## 4. 위젯 카탈로그

모두 16종입니다. 편집 모드에서 팔레트의 "Add Widget"으로 추가합니다.

### 정보 임베드

| 위젯 | 무엇을 | 언제 쓰나 |
|---|---|---|
| **Webpage** | 웹앱·웹페이지를 작업판 안에 임베드 | 자주 쓰는 콘솔·문서·메일을 탭처럼 한 화면에 박아두고 싶을 때 |
| **Web Query** | 검색어의 변하는 부분만 입력해 검색 엔진/사이트에 질의 | 같은 사이트에 반복 검색할 때(구글·네이버·나무위키·ChatGPT 등 다수 내장) |

### 메모 / 할 일

| 위젯 | 무엇을 | 언제 쓰나 |
|---|---|---|
| **Note** | 빠른 메모(생각·아이디어·중요 정보). 공유 키로 여러 워크플로우에서 같은 노트 공유 가능 | 항상 눈앞에 둘 메모, 또는 여러 작업판에서 공유할 메모 |
| **To-Do List** | 간단한 할 일 목록. 같은 프로젝트 안에서 자동 동기화 | 프로젝트 단위 할 일을 어느 워크플로우에서든 함께 보고 싶을 때 |

### 파일 · 실행

| 위젯 | 무엇을 | 언제 쓰나 |
|---|---|---|
| **File Explorer** | 즐겨찾기 폴더들을 트리로 보여주고 더블클릭으로 OS 기본 앱에서 열기 | 자주 들어가는 폴더 몇 개를 한눈에 두고 탐색할 때 |
| **File Opener** | 등록한 파일·폴더를 버튼 클릭 한 번으로 연결된 앱에서 열기 | 특정 파일/폴더를 빠르게 열어야 할 때 |
| **Link Opener** | 등록한 링크(또는 링크 묶음)를 브라우저로 한 번에 열기 | 매번 함께 여는 사이트 세트가 있을 때 |
| **Commander** | 명령줄을 등록해 터미널에서 클릭 한 번으로 실행 | 자주 치는 명령(빌드·배포·스크립트)을 버튼화할 때 |

### 시간 관리

| 위젯 | 무엇을 | 언제 쓰나 |
|---|---|---|
| **Timer** | 클릭으로 시작하는 카운트다운, 종료 시 알림(일시정지/재개) | 짧은 집중·휴식·삶기 타이머 등 |
| **Stopwatch** | 0부터 올라가는 스톱워치(1/100초, 시작·일시정지·리셋) | 경과 시간을 재야 할 때 |
| **Pomodoro** | 작업/휴식을 번갈아 반복하는 타이머(전환음·완료 세션 수) | 뽀모도로 기법으로 집중 리듬을 만들 때 |
| **Clock** | 현재 시각 + 멀티 타임존(세계시계, 12/24h·초·날짜 토글) | 다른 시간대 동료·시장과 일할 때 |
| **D-Day** | 여러 목표 날짜까지(또는 지난 후)를 D-30·D-DAY·D+15로 표시 | 마감·기념일 카운트다운 |

### 도구

| 위젯 | 무엇을 | 언제 쓰나 |
|---|---|---|
| **Calculator** | 버튼·키보드 입력 사칙연산 계산기 | 잠깐 계산할 때 |
| **System Monitor** | 내 컴퓨터의 CPU·RAM 사용량 실시간 표시 | 무거운 작업 중 자원을 곁눈질할 때 |

> 각 위젯의 포크 추가 기능(자동 아이콘, 동적 타이틀, 단축키 등)의 자세한 내역은 [`docs/CHANGES.md`](CHANGES.md)에 정리돼 있습니다.

## 5. 단축키 & 꿀팁

### 단축키

| 동작 | Windows / Linux | macOS |
|---|---|---|
| 프리터 불러내기/숨기기 (글로벌) | `Ctrl`+`Shift`+`Space` | `Cmd`+`Shift`+`Space` |
| 편집 모드 켜기/끄기 | `Ctrl`+`E` | `Cmd`+`E` |
| 다음 워크플로우 | `Ctrl`+`Tab` | `Cmd`+`Tab` |
| 이전 워크플로우 | `Ctrl`+`Shift`+`Tab` | `Cmd`+`Shift`+`Tab` |
| 앱 설정 열기 | `Ctrl`+`,` | `Cmd`+`,` |

**Webpage 위젯**에 포커스가 있을 때(위젯별 동작):

| 동작 | 키 |
|---|---|
| 뒤로 / 앞으로 | `Alt`+`←` / `Alt`+`→` |
| 새로고침 | `F5` 또는 `Ctrl`/`Cmd`+`R` |
| 확대 / 축소 / 원래대로 | `Ctrl`/`Cmd`+`Shift`+`=` / `Ctrl`/`Cmd`+`-` / `Ctrl`/`Cmd`+`0` (또는 `Ctrl`/`Cmd`+마우스 휠) |
| 페이지 내 찾기 | `Ctrl`/`Cmd`+`F` |
| 시작 페이지로 이동 | `Alt`+`Home` |
| 현재 페이지를 기본 브라우저로 열기 | `Ctrl`/`Cmd`+`T` |

> 글로벌 단축키는 앱 설정에서 다른 조합으로 바꾸거나 끌 수 있습니다.

### 꿀팁

- **앱 설정(`Ctrl`/`Cmd`+`,`)에서 바꿀 수 있는 것**: 글로벌 단축키 조합, 워크플로우 바 위치(상/하/좌/우), 작업판 배경(색·이미지), Webpage 다운로드 폴더, 테마, 메모리 세이버 임계값.
- **셸프(탑 바)** 에는 프로젝트와 무관하게 늘 곁에 둘 위젯을 올리세요. 위젯을 복사해 탑 바의 "Paste Widget"에서 끌어다 놓습니다.
- **Note 공유**: 한 노트를 여러 워크플로우에서 같이 보려면 Note 설정에서 공유 키를 만들어 다른 Note에도 같은 키를 지정하세요.
- **To-Do List**는 설정 없이도 같은 프로젝트 안에서 자동으로 동기화됩니다.

## 6. 데이터 보관·백업 / FAQ

### 내 데이터는 어디에?

- 위치: `<appData>/freeter-swh/freeter-data/`
  - Windows: `%APPDATA%\freeter-swh\freeter-data\`
  - 메뉴 **File → Open Data Folder**(또는 macOS는 앱 메뉴)로 OS 탐색기에서 바로 열 수 있습니다.
- 내부에는 앱 상태 파일과 `widgets/<위젯id>/`(위젯별 데이터)가 들어 있습니다.

### 백업하려면?

위 **데이터 폴더를 통째로 복사**하면 됩니다. 다른 컴퓨터에 같은 위치로 복원하면 그대로 옮겨집니다.

### FAQ

**Q. 원본 Freeter와 같이 깔아 써도 되나요?**
네. 이 포크는 앱 식별자·이름·데이터 폴더가 모두 분리돼 있어서 원본과 **동시에 설치·실행**해도 서로 간섭하지 않습니다.

**Q. 데이터가 클라우드로 동기화되나요?**
아니요. 모든 데이터는 **로컬에 저장**됩니다. 동기화가 필요하면 데이터 폴더를 직접 클라우드 동기화 폴더에 두거나 백업하세요.

**Q. 방금 추가한 위젯이 안 보여요 / 옮길 수가 없어요.**
**편집 모드**가 꺼져 있을 가능성이 큽니다. 연필 아이콘 또는 `Ctrl`/`Cmd`+`E`로 켜세요. 위젯 추가·이동·리사이즈는 편집 모드에서만 됩니다.

**Q. 한참 안 본 워크플로우로 돌아오니 잠깐 비어 보였어요.**
**메모리 세이버**가 자원을 아끼려 내려둔 것으로, 다시 열면 복구됩니다. 앱 설정에서 임계값을 조정할 수 있습니다.
